# Brighton Weekend v47 — Event data deep dive

Refresh date: 11 September 2026.

Sources used: Ents24 venue calendars, official venue calendars/pages where available, Ticketmaster venue listings for DUST, Eventbrite discovery pages/results, and existing Brighton Weekend event data.

The refresh covers the existing venues plus the seven venues added in v46. It removes obvious cancelled/moved listings where identified and does not invent missing start times.

Primary venue sources include: Brighton Centre, Brighton Dome, CHALK, Concorde 2, The Old Market, Green Door Store, Volks, Quarters, Patterns, DUST, Komedia, The Forge Comedy Club, Theatre Royal Brighton, Hope & Ruin, The Prince Albert, A L P H A B E T, The Pipeline, Brighton Racecourse, The Gladstone and Babble.

Eventbrite was used as a discovery/cross-check source, including specific listings for DUST, Concorde 2 and CHALK.
